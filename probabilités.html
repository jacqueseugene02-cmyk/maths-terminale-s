1. Vocabulaire

Une expérience aléatoire est une expérience dont on ne peut pas prévoir avec certitude le résultat.

L'ensemble de tous les résultats possibles est appelé univers, noté généralement Ω.

Un événement est un ensemble de résultats de l'expérience.

2. Probabilité d'un événement

La probabilité d'un événement A est notée :

P(A)

On a toujours :

0 ≤ P(A) ≤ 1

Pour l'événement certain :

P(Ω) = 1

Pour l'événement impossible :

P(∅) = 0

3. Événement contraire

L'événement contraire de A est noté Ā.

Sa probabilité est :

P(Ā) = 1 - P(A)

Donc :

P(A) + P(Ā) = 1

4. Union et intersection

L'événement A ∩ B signifie : A et B se réalisent simultanément.

L'événement A ∪ B signifie : A ou B se réalise.

Formule générale :

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

5. Probabilité conditionnelle

La probabilité de A sachant B est notée :

PB(A)

ou :

P(A | B)

Si P(B) ≠ 0 :

P(A | B) = P(A ∩ B) / P(B)

6. Formule du produit

À partir de la probabilité conditionnelle :

P(A ∩ B) = P(B) × P(A | B)

On peut également écrire :

P(A ∩ B) = P(A) × P(B | A)

7. Indépendance

Deux événements A et B sont indépendants si :

P(A ∩ B) = P(A) × P(B)

Lorsque P(B) ≠ 0, cela revient à :

P(A | B) = P(A)

8. Formule des probabilités totales

Supposons que B et son contraire forment une partition de l'univers.

Alors :

P(A) = P(B)P(A | B) + P( B̄ )P(A | B̄)

Cette formule est très utile avec les arbres de probabilités.

9. Arbre de probabilités

Dans un arbre pondéré, les probabilités sont placées sur les branches.

Pour calculer la probabilité d'un chemin, on multiplie les probabilités rencontrées sur ce chemin.

Pour calculer la probabilité de plusieurs chemins, on additionne leurs probabilités.

10. Loi binomiale

Une variable aléatoire X suit une loi binomiale de paramètres n et p lorsque :

X ~ B(n ; p)

où :

  • n est le nombre de répétitions ;
  • p est la probabilité du succès ;
  • les répétitions sont indépendantes.

11. Probabilité d'obtenir k succès

Si X suit une loi binomiale B(n ; p), alors :

P(X = k) = C(n,k) pk (1-p)n-k

où C(n,k) représente le nombre de combinaisons de k éléments parmi n.

12. Espérance d'une loi binomiale

Si :

X ~ B(n ; p)

alors son espérance est :

E(X) = np

💡 Exemple corrigé

Situation

Un joueur réussit un tir avec une probabilité de 0,7.

Il effectue 5 tirs indépendants.

Soit X le nombre de tirs réussis.

Alors :

X ~ B(5 ; 0,7)

Calculons P(X = 3).

P(X = 3) = C(5,3) × 0,7³ × 0,3²

C(5,3) = 10

Donc :

P(X = 3) = 10 × 0,343 × 0,09

P(X = 3) = 0,3087

🔥 Exercice 1

Une urne contient 4 boules rouges et 6 boules bleues.

On tire une boule au hasard.

1. Calculer la probabilité d'obtenir une boule rouge.

2. Calculer la probabilité d'obtenir une boule bleue.

🚀 Exercice 2 — Loi binomiale

Une machine produit une pièce défectueuse avec une probabilité de 0,02.

On choisit 10 pièces indépendamment.

Soit X le nombre de pièces défectueuses.

1. Donner la loi de X.

2. Calculer P(X = 1).

3. Calculer E(X).
