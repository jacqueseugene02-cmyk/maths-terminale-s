1. Introduction

La dérivation est un outil essentiel permettant d'étudier les variations d'une fonction.

Elle permet notamment de déterminer les intervalles où une fonction est croissante ou décroissante et de rechercher ses extrema.

2. Définition de la dérivée

Soit f une fonction définie sur un intervalle. Si f est dérivable en un point a, son nombre dérivé en a est noté :

f'(a)

Il représente le coefficient directeur de la tangente à la courbe de f au point d'abscisse a.

3. Formules de dérivation

Voici quelques dérivées fondamentales :

  • (xⁿ)' = nxⁿ⁻¹
  • (x)' = 1
  • (c)' = 0
  • (eˣ)' = eˣ
  • (ln x)' = 1/x
  • (sin x)' = cos x
  • (cos x)' = -sin x

4. Règles de dérivation

Somme

(f + g)' = f' + g'

Produit

(fg)' = f'g + fg'

Quotient

(f/g)' = (f'g - fg') / g²

5. Signe de la dérivée et variations

La dérivée permet de déterminer les variations d'une fonction.

  • Si f'(x) > 0, alors f est croissante.
  • Si f'(x) < 0, alors f est décroissante.
  • Si f'(x) = 0, il peut y avoir un extremum.

💡 Exemple corrigé

Étudier les variations de f

Soit :

f(x) = x² - 4x + 3

Étape 1 : calcul de la dérivée

f'(x) = 2x - 4

Étape 2 : recherche du signe

f'(x) = 0 lorsque :

2x - 4 = 0

donc :

x = 2

Étape 3 : variations

Pour x < 2, f'(x) < 0.

La fonction est donc décroissante sur ]−∞ ; 2].

Pour x > 2, f'(x) > 0.
