1. Introduction aux nombres complexes

Dans l'ensemble des nombres réels, l'équation

x² + 1 = 0

n'a pas de solution car x² est toujours positif ou nul.

On introduit donc un nouveau nombre noté i, défini par :

i² = -1

L'ensemble des nombres complexes est noté ℂ.

2. Forme algébrique

Tout nombre complexe z peut s'écrire de manière unique :

z = a + bi

où a et b sont des nombres réels.

a est la partie réelle de z.

b est la partie imaginaire de z.

Exemple

Soit :

z = 4 - 7i

Alors :

Re(z) = 4

Im(z) = -7

3. Égalité de deux nombres complexes

Deux nombres complexes sont égaux si et seulement si leurs parties réelles sont égales et leurs parties imaginaires sont égales.

Si :

z = a + bi

et :

z' = c + di

alors :

z = z' ⇔ a = c et b = d

Exemple

Résoudre :

(2x + 1) + (y - 3)i = 5 + 4i

On identifie les parties réelles :

2x + 1 = 5

donc x = 2.

Puis les parties imaginaires :

y - 3 = 4

donc y = 7.

4. Addition et soustraction

Soient :

z₁ = a + bi

z₂ = c + di

Alors :

z₁ + z₂ = (a+c) + (b+d)i

et :

z₁ - z₂ = (a-c) + (b-d)i

Exemple

z₁ = 3 + 2i

z₂ = 1 - 5i

z₁ + z₂ = 4 - 3i

z₁ - z₂ = 2 + 7i

5. Multiplication

Pour multiplier deux nombres complexes, on développe comme avec des expressions algébriques.

(a+bi)(c+di)

= ac + adi + bci + bdi²

Comme i² = -1 :

(a+bi)(c+di) = (ac-bd)+(ad+bc)i

Exemple

Calculons :

(2+3i)(1-2i)

= 2 - 4i + 3i - 6i²

= 2 - i + 6

= 8 - i

6. Conjugué d'un nombre complexe

Si :

z = a + bi

alors son conjugué est :

z̄ = a - bi

Exemple

Si :

z = 5 + 3i

alors :

z̄ = 5 - 3i

Propriété importante

z × z̄ = |z|²

7. Module d'un nombre complexe

Pour :

z = a + bi

son module est :

|z| = √(a²+b²)

Exemple

Soit :

z = 3 + 4i

Alors :

|z| = √(3²+4²)

|z| = 5

8. Inverse d'un nombre complexe

Pour z ≠ 0 :

1/z = z̄/|z|²

Exemple

Calculons :

1/(2+3i)

Le conjugué de 2+3i est 2-3i.

|2+3i|² = 2²+3² = 13.

Donc :

1/(2+3i) = (2-3i)/13

9. Division de nombres complexes

Pour effectuer une division, on multiplie le numérateur et le dénominateur par le conjugué du dénominateur.

Exemple

Calculons :

(1+i)/(2-i)

On multiplie par 2+i :

[(1+i)(2+i)] / [(2-i)(2+i)]

Numérateur :

2+i+2i+i² = 1+3i

Dénominateur :

4-i² = 5

Donc :

(1+i)/(2-i) = 1/5 + 3/5i

10. Interprétation géométrique

À tout nombre complexe :

z = a+bi

on peut associer un point M de coordonnées :

M(a ; b)

dans un plan muni d'un repère orthonormé.

Le point M est appelé l'image de z.

Le vecteur OM a pour coordonnées :

(a ; b)

11. Argument d'un nombre complexe

Pour un nombre complexe non nul z, un argument de z est un angle θ tel que :

cos(θ) = a/|z|

et :

sin(θ) = b/|z|

On note généralement :

arg(z) = θ

12. Forme trigonométrique

Si z est non nul, alors :

z = r(cos θ + i sin θ)

où :

  • r = |z|
  • θ est un argument de z

Exemple

Pour :

z = 1+i

son module vaut :

r = √2

et un argument est :

θ = π/4

Donc :

z = √2(cos(π/4)+i sin(π/4))

13. Forme exponentielle

Grâce à la formule d'Euler :

eⁱᶿ = cos θ + i sin θ

la forme trigonométrique peut s'écrire :

z = reⁱᶿ

Cette forme est particulièrement utile pour effectuer des produits, quotients et puissances.

14. Produit et quotient sous forme exponentielle

Si :

z₁ = r₁eⁱᵅ

z₂ = r₂eⁱᵝ

alors :

z₁z₂ = r₁r₂eⁱ⁽ᵅ⁺ᵝ⁾

et :

z₁/z₂ = (r₁/r₂)eⁱ⁽ᵅ⁻ᵝ⁾

15. Formule de Moivre

Pour tout entier n :

(cos θ + i sin θ)ⁿ = cos(nθ)+i sin(nθ)

Cette formule permet notamment de calculer des puissances de nombres complexes.

16. Résolution d'équations complexes

Exemple 1

Résolvons :

z² + 4 = 0

z² = -4

Comme i² = -1 :

z = 2i ou z = -2i

Exemple 2

Résolvons :

z² - 2z + 5 = 0

Δ = (-2)² - 4×1×5

Δ = -16

√Δ = 4i

Donc :

z₁ = 1+2i

z₂ = 1-2i

17. Nombres complexes et géométrie

Les nombres complexes permettent de traduire de nombreux problèmes géométriques.

Pour deux points A et B d'affixes zA et zB, l'affixe du vecteur AB est :

zB - zA

La distance AB est :

AB = |zB-zA|

Cette relation est très utile pour démontrer des égalités de longueurs.
