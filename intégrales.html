1. Notion de primitive

Soit f une fonction définie sur un intervalle I. Une fonction F est une primitive de f sur I si :

F'(x) = f(x)

Autrement dit, une primitive permet de retrouver une fonction à partir de sa dérivée.

2. Primitives usuelles

  • xⁿ → xⁿ⁺¹/(n + 1) pour n ≠ −1
  • 1/x → ln|x|
  • eˣ → eˣ
  • cos(x) → sin(x)
  • sin(x) → −cos(x)

À une constante près, toutes les primitives d'une même fonction sont de la forme :

F(x) + C

3. Intégrale définie

Si F est une primitive de f sur [a ; b], alors :

∫ₐᵇ f(x) dx = F(b) − F(a)

Cette relation est appelée la formule fondamentale du calcul intégral.

4. Propriétés de l'intégrale

Linéarité

∫ₐᵇ [λf(x) + μg(x)]dx = λ∫ₐᵇf(x)dx + μ∫ₐᵇg(x)dx

Relation de Chasles

Pour a, b et c :

∫ₐᶜ f(x)dx = ∫ₐᵇ f(x)dx + ∫ᵦᶜ f(x)dx

5. Calcul d'une intégrale

Exemple

Calculons :

∫₀² 3x² dx

Une primitive de 3x² est :

F(x) = x³

Donc :

∫₀² 3x²dx = F(2) − F(0)

= 2³ − 0³

= 8

6. Intégrale et aire

Lorsque f est positive sur [a ; b], l'intégrale :

∫ₐᵇ f(x)dx

représente l'aire située entre la courbe de f, l'axe des abscisses et les droites x = a et x = b.

L'unité d'aire dépend des unités utilisées sur les axes du graphique.

💡 Exemple plus avancé

Calculer une intégrale

Calculons :

I = ∫₁³ (2x + 1)dx

Une primitive de 2x + 1 est :

F(x) = x² + x

Donc :

I = F(3) − F(1)

I = (9 + 3) − (1 + 1)

I = 10
