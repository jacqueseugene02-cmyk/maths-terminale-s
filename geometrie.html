1. Repérage dans l'espace

Dans l'espace, on utilise un repère (O ; i ; j ; k).

Un point M possède trois coordonnées :

M(x ; y ; z)

x, y et z sont les coordonnées du point M.

2. Coordonnées d'un vecteur

Soient deux points :

A(xA ; yA ; zA)

B(xB ; yB ; zB)

Alors :

AB⃗ = (xB-xA ; yB-yA ; zB-zA)

Exemple

A(1 ; 2 ; 3)

B(4 ; 6 ; 5)

AB⃗ = (3 ; 4 ; 2)

3. Norme d'un vecteur

Si :

u⃗ = (x ; y ; z)

alors :

||u⃗|| = √(x² + y² + z²)

Exemple

u⃗ = (2 ; 3 ; 6)

||u⃗|| = √(4 + 9 + 36)

||u⃗|| = 7

4. Distance entre deux points

La distance AB est la norme du vecteur AB⃗ :

AB = ||AB⃗||

Donc :

AB = √[(xB-xA)² +(yB-yA)² +(zB-zA)²]

5. Produit scalaire

Soient :

u⃗ = (x ; y ; z)

v⃗ = (x' ; y' ; z')

Leur produit scalaire est :

u⃗ · v⃗ = xx' + yy' + zz'

Deux vecteurs non nuls sont orthogonaux si :

u⃗ · v⃗ = 0

6. Équation paramétrique d'une droite

Une droite passant par A et de vecteur directeur u⃗ peut être représentée par :

M = A + t u⃗

où t est un nombre réel.

Si :

A(xA ; yA ; zA)

et :

u⃗ = (a ; b ; c)

alors :

x = xA + at

y = yA + bt

z = zA + ct

7. Équation cartésienne d'un plan

Un plan peut avoir une équation de la forme :

ax + by + cz + d = 0

Le vecteur :

n⃗ = (a ; b ; c)

est un vecteur normal au plan.

8. Droite et plan

Pour étudier la position d'une droite par rapport à un plan, on peut utiliser un vecteur directeur de la droite et un vecteur normal au plan.

Si le vecteur directeur u⃗ est colinéaire au vecteur normal n⃗, alors la droite est perpendiculaire au plan.

u⃗ = λn⃗

9. Plans parallèles

Deux plans sont parallèles lorsque leurs vecteurs normaux sont colinéaires.

Si :

n⃗₁ = λn⃗₂

alors les deux plans sont parallèles ou confondus.

10. Droites parallèles

Deux droites sont parallèles lorsque leurs vecteurs directeurs sont colinéaires.

u⃗ = λv⃗

11. Intersection d'une droite et d'un plan

Pour déterminer le point d'intersection d'une droite et d'un plan, on remplace les coordonnées paramétriques de la droite dans l'équation du plan.

On obtient alors une équation en t.

Après avoir trouvé t, on remplace cette valeur dans les équations de la droite.

12. Exemple corrigé

Soit la droite :

x = 1 + 2t

y = 3 - t

z = 2 + t

et le plan :

x + y + z - 7 = 0

On remplace :

(1+2t)+(3-t)+(2+t)-7 = 0

2t - t + t + 6 - 7 = 0

2t - 1 = 0

t = 1/2

Le point d'intersection est donc :

M(2 ; 5/2 ; 5/2)
