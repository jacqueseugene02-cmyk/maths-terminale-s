🔵 Théorie des graphes

Maths Terminale S

1. Introduction

La théorie des graphes est une branche des mathématiques qui permet d'étudier des relations entre différents objets.

Un graphe peut être utilisé pour représenter un réseau routier, un réseau informatique, les liaisons entre des villes ou encore les relations entre plusieurs personnes.

2. Vocabulaire

🔹 Sommet

Un sommet représente un objet ou un élément du problème. On le représente généralement par un point.

🔹 Arête

Une arête représente une relation entre deux sommets. Elle est généralement représentée par un segment reliant deux sommets.

Exemple :

Si A et B sont deux sommets reliés, on peut écrire : A — B

3. Graphe non orienté

Dans un graphe non orienté, les arêtes n'ont pas de direction.

Ainsi, si A est relié à B, alors B est également relié à A.

Exemple :

A — B — C

Les sommets A, B et C sont reliés par des arêtes.

4. Graphe orienté

Dans un graphe orienté, les relations possèdent une direction. Une flèche indique le sens de la relation.

Exemple :

A → B → C

Ici, la relation va de A vers B puis de B vers C.

5. Degré d'un sommet

Dans un graphe non orienté, le degré d'un sommet est le nombre d'arêtes qui arrivent à ce sommet.

Exemple :

Si le sommet A est relié à B, C et D, alors :

deg(A) = 3

6. Chaîne

Une chaîne est une succession de sommets reliés par des arêtes.

Exemple :

A — B — C — D

La succession A → B → C → D constitue une chaîne.

7. Chemin

Dans un graphe orienté, un chemin respecte le sens des flèches.

Exemple :

A → B → C → D

On peut aller de A vers D en suivant les flèches.

8. Cycle

Un cycle est une chaîne qui revient à son sommet de départ.

Exemple :

A → B → C → A

On part de A et on revient à A.

9. Graphe connexe

Un graphe est connexe lorsque tous ses sommets peuvent être reliés entre eux par une chaîne.

Autrement dit, il est possible de partir d'un sommet quelconque et d'atteindre les autres sommets.

10. Matrice d'adjacence

La matrice d'adjacence permet de représenter un graphe sous forme de tableau.

Pour un graphe comportant n sommets, on construit une matrice à n lignes et n colonnes.

Dans un graphe non orienté simple :

  • on met 1 si deux sommets sont reliés ;
  • on met 0 s'ils ne sont pas reliés.

11. Exemple

Considérons les sommets A, B et C avec les arêtes :

A — B et B — C

La matrice d'adjacence est :

    A B C
A  0 1 0
B  1 0 1
C  0 1 0

12. À retenir 📌

  • Un graphe est constitué de sommets et d'arêtes.
  • Une arête relie deux sommets.
  • Un graphe peut être orienté ou non orienté.
  • Le degré d'un sommet correspond au nombre d'arêtes qui lui sont incidentes.
  • Une chaîne est une succession de sommets reliés.
  • Un cycle revient à son sommet de départ.
  • La matrice d'adjacence permet de représenter un graphe sous forme matricielle.
