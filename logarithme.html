1. Définition

La fonction logarithme népérien, notée ln, est définie sur l'ensemble des réels strictement positifs.

Son domaine de définition est donc :

]0 ; +∞[

Le logarithme népérien est la fonction réciproque de la fonction exponentielle.

2. Propriétés fondamentales

Pour a > 0 et b > 0 :

  • ln(1) = 0
  • ln(e) = 1
  • ln(ab) = ln(a) + ln(b)
  • ln(a/b) = ln(a) - ln(b)
  • ln(aⁿ) = n ln(a)

3. Lien entre ln et exp

Les fonctions logarithme et exponentielle sont réciproques.

Ainsi :

ln(eˣ) = x

et :

eˡⁿˣ = x

pour tout x > 0.

4. Dérivée du logarithme

Pour x > 0 :

(ln x)' = 1/x

Cas général

Si u(x) > 0, alors :

(ln(u(x)))' = u'(x) / u(x)

5. Variations de ln(x)

Pour x > 0 :

(ln x)' = 1/x

Or :

1/x > 0

Donc la fonction ln est strictement croissante sur ]0 ; +∞[.

6. Limites importantes

Lorsque x tend vers 0 par valeurs positives :

lim ln(x) = −∞

Lorsque x tend vers +∞ :

lim ln(x) = +∞

💡 Exemple corrigé

Résoudre une équation

Résolvons :

ln(x) = 3

On applique la fonction exponentielle aux deux membres :

eˡⁿˣ = e³

Donc :

x = e³

🔥 Exemple avancé

Étude d'une fonction

Soit :

f(x) = x ln(x)

Pour x > 0 :

f'(x) = ln(x) + 1

Cherchons quand f'(x) = 0 :

ln(x) + 1 = 0

ln(x) = -1

x = e⁻¹ = 1/e
