1. Notion de limite

La limite d'une fonction permet d'étudier le comportement de cette fonction lorsque la variable se rapproche d'une valeur donnée ou lorsqu'elle devient très grande.

On écrit par exemple :

lim f(x) = L

lorsque x tend vers une valeur donnée.

2. Limite en un point

Définition

On dit que la limite de f(x) lorsque x tend vers a est L si f(x) se rapproche de plus en plus de L lorsque x se rapproche de a.

Notation

lim f(x) = L

avec x → a.

3. Limite à l'infini

On étudie le comportement de la fonction lorsque x devient très grand ou très petit.

Exemple

Pour la fonction :

f(x) = 1/x

lorsque x devient très grand :

lim 1/x = 0

lorsque x → +∞.

4. Opérations sur les limites

Si :

lim f(x) = L

et

lim g(x) = M

alors, lorsque les opérations ont un sens :

  • lim(f + g) = L + M
  • lim(f - g) = L - M
  • lim(f × g) = L × M
  • lim(f / g) = L / M lorsque M ≠ 0

5. Formes indéterminées

Certaines opérations sur les limites conduisent à des formes qui nécessitent une étude particulière.

Les principales formes indéterminées

  • ∞ − ∞
  • 0 × ∞
  • 0 / 0
  • ∞ / ∞

Il faut alors transformer l'expression avant de calculer la limite.

6. Continuité

Définition

Une fonction f est continue en un point a lorsque :

lim f(x) = f(a)

lorsque x tend vers a.

7. Théorème des valeurs intermédiaires

Si une fonction est continue sur un intervalle et qu'elle prend deux valeurs différentes aux extrémités de cet intervalle, alors elle prend toutes les valeurs intermédiaires.

Ce théorème est notamment utilisé pour montrer l'existence d'une solution à une équation.

💡 Exemple corrigé

Calculer une limite

Calculons :

lim (2x + 3) lorsque x → +∞

Lorsque x devient très grand, le terme 2x devient également très grand.

Donc :

lim (2x + 3) = +∞
